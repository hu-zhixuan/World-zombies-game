# 现在做到哪，下一步做什么

> 先读 `CLAUDE.md`（交接摘要）、`architecture.md`（分层与画面规矩）和 `redesign_proposal.md`（玩法总体方向）。

## 已经做完的（截至 `v57.2`）

### 1. 基础架构（M0 ～ M4 核心闭环已合入）
- 旧版代码完整保留在 `legacy/`；新版采用 `TypeScript + Phaser 3.90 + Preact + vite-plugin-singlefile`，构建产物仍是单个离线 HTML（`dist/index.html`），可直接打进 Android WebView APK。
- 规则层（`src/sim/`）与画面层（`src/view/`）、界面层（`src/ui/`）彻底解耦：规则层纯计算，每秒 60 步，支持带种子复现与机器人（`src/sim/bot.ts`）自动跑完 15 天测试。

### 2. 元气骑士式手操手感、可控抛物线手雷与视觉动效（`v57.2` 新增核心体验）
- **停止默认自动乱打，改为「按住攻击自动锁敌」**：
  - `newRun()` 默认 `autoFire = false`，角色站岗或走位时绝不擅自开枪空耗弹匣；锁定目标会预先显示准星框，但只在玩家按下/按住 `#key-fire` 时向锁敌精准射杀（无敌人在射程内时也能按面朝方向手动盲射）。
  - 下层触控对短按做了脉冲锁存（`<16ms` 快点也保证稳稳打出至少一发），松手即停。
- **可拖拽控制抛物线的手榴弹轮盘**：
  - 通过共享物理公式 `computeGrenadeThrow(run, aim)` 解算初始速度，战斗中按住 `#key-grenade` 向任意方向拖拽，可实时控制投掷距离（`-150px ～ +440px`）与高抛/低平抛弧度（`15 ～ 68` 帧浮空时间）。
  - 画面层实时绘制基于同一物理逻辑（含空中撞怪截停与地面落点）的渐隐抛物线点阵、脉冲爆炸预警环、红叉准星以及爆区内僵尸金色高亮；上拉可越过前排骷髅盾兵直接炸后排喷火食尸鬼，快点仍可智能抛向最近尸群。
- **左下浮动摇杆 & 右下弧形按键精调**：
  - 左下 `.pad-zone` 覆盖左下角 `38% × 60%` 宽裕热区，圈外触碰瞬移抓杆、超距 `54px` 牵引跟随防反向卡顿、`7%` 极小死区 + `0.38 ～ 1.0` 线性起步曲率。
  - 右下 `.keys-fan` 围绕 `82×82` 金环主攻击键（按住即时发光）弧形排布跳跃、闪避、手雷、技能 4 枚像素图标按键，带环形冷却进度指示与相互零重叠净空。
- **双段前瞻 WebAudio 合成配乐 & 战斗视听反馈**：
  - 采用 `35ms` 前瞻音频调度器 + 低通反馈立体声回声总线，实现零卡拍的 64 步 A/B 段白天像素摇滚战歌、Boss 狂飙曲、夜晚酒馆爵士小调，以及连杀音阶升调、切枪、跳跃、手雷拖曳刻度音效。
  - 主角实体手里握持对应武器贴图并随瞄准角度旋转与后坐上抬，搭配退壳弹跳铜壳、受击挤压闪烁、冲刺寒霜残影、像素火花与四角收缩锁敌框。

### 3. 白天屋顶塔防与 2D 实体物理（M1 ～ M2）
- **2D 小屋实体碰撞与阶梯跳台**：
  - 小屋一楼右侧设有实体砖墙阻挡（`HOUSE_WALL_X = 246`），在地面往左走会被实打实挡在门外，不会穿进屋体贴图；门廊外侧搭有中层木挑台（`PORCH_Y = -48`）与二层屋顶防守木平台（`ROOF_Y = -92`），玩家可从地面按跳跃键分两跳亲自跳上二楼房顶，站在房顶自带 `+15%` 居高射程加成。
- **8 把特色武器与升星系统**：
  - 战术手枪（击杀回 2 发）、左轮（穿甲 2 人 + 重击退）、冲锋枪（6 发/秒极速弹幕）、霰弹枪（近身 1.4x 轰飞）、急冻步枪（减速+碎冰爆裂）、反器材狙（全屏磁轨光束）、电浆炮（连环感电 3 次）、火箭筒（焦土燃烧爆破）。随身最多带 3 把，同款升星最高 ★5。
- **统一哥特像素亡灵、4 炮塔槽位与 3 级路障/堡垒**：
  - 全面使用 ansimuz Gothicvania 哥特亡灵，第 5/10/15 天三大 Boss 登场；2 个屋顶塔位 + 2 个庭院塔位（机枪/冰霜/电弧/重炮）；路障与堡垒 3 级外观与机制升级。
