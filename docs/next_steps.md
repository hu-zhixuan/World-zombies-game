## 瞄准是怎么改的（作者说 v56.4 的不行）

旧版的问题：主角站在高处往斜下方打，必须瞄；开火键兼做瞄准摇杆，手指稍微一偏就变成手动瞄准打歪；僵尸从按键底下进场。

新版的做法：
- 主角和僵尸在同一条街上，子弹基本是平着飞的，**不需要瞄**。
- 按住开火 = 自动转身、自动打射程内最近的一只，脚下红圈 + 头顶红箭头标出打的是谁。锁住后不会来回跳。
- 开火键只管开火，没有拖动瞄准，不会误触。
- 射程外不锁、不乱转身、不开枪（按住等僵尸过来不会白白打空弹匣）。

还没做、可以后面加的：点一下某只僵尸指定先打它（精英怪出现后才有用）。**作者试过预览版后，如果还觉得不对，要问清楚具体是哪里不对再改。**
