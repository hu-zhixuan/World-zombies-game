# 现在做到哪，下一步做什么

> 先读 `CLAUDE.md`（交接摘要）、`architecture.md`（分层与画面规矩）和 `redesign_proposal.md`（玩法总体方向）。

## 已经做完的（截至 `v57.5`）

### 1. 基础架构（M0 ～ M4 核心闭环完整落地）
- 旧版代码完整保留在 `legacy/`；新版采用 `TypeScript + Phaser 3.90 + Preact + vite-plugin-singlefile`，构建产物仍是单个离线 HTML（`dist/index.html`），可直接打进 Android WebView APK。
- 规则层（`src/sim/`）与画面层（`src/view/`）、界面层（`src/ui/`）彻底解耦：规则层纯计算，每秒 60 步，支持带种子复现与机器人（`src/sim/bot.ts`）自动跑完 15 天测试。

### 2. 手部建模重做与持枪衔接（`v57.5`）
- 从 `player.ase` 分离原版写死的武器与前臂层，提取无枪躯干动画（`hero_idle/run/shoot/crouch/jump/fall/hurt`）+ 独立夹克手臂右拳（`hero_arm`，`15x8`）+ 室内轻快垂摆手臂（`hero_arm_rest`，`6x12`）。
- 8 把枪按各自握把锚点（`WEAPON_GRIP`）精准贴合拳心，随自动锁敌/手动朝向实时旋转并触发后坐力上扬与退移；室内彻底脱枪漫步，室外出生位调至 `x=194`，远离前哨炮塔与守卫火炮，彻底告别双枪穿模与浮空。

### 3. 深夜食堂去杂优化与经营体系（`v57.3` + `v57.5` 去杂）
- **屋内酒馆去杂**：去掉壁炉乱转火球、遮挡双拱窗的暗色 `...` 对白框与多余跳动箭头，桌面清理留白让端上的热菜稳定摆在橡木桌面；3 位食客错开落座两张木桌不重叠，交互提示统一由脚底微光带与 `CampDock` 按钮金边高亮承接，不再重复遮挡屏幕。
- **食堂弹窗重构**：标题行与「今夜堂食 / 特餐(6) / 图鉴(15)」页签合为单排、粉丝/热搜/明日特餐收拢为一条 `.diner-ribbon`、清除热搜 `#` 号井字格噪点、重切 6 道菜品居中高辨识度像素图标（`ic_dish_*`），三列堂食卡片 `minmax(0, 1fr)` 等宽齐整不横向裁切。
- **铁板火候烹制 QTE & 15 位 VIP 图鉴**：保留铁板火候条（一般/不错/完美/传说）与快手出菜、6 道随天数解锁食谱、5 阶 15 位熟客初遇档案与食评墙。

### 4. 战斗强打击感全面升级（`v57.5`）
- **开火反馈**：8 把枪分化枪口多向火舌斩光、退壳弹道、差异化枪口后坐力/屏幕震动与方向性机位推拉（`camKickX`）。
- **受击与击杀爽感**：暴击/重武器命中触发 `45ms` 僵尸微卡肉顿帧（`hitStop`）、高频受击震颤（`jitter`）、水平挤压回弹（`1.18×/0.84×`）、击退后仰角与方向性火花碎肉锥；暴击/击杀/爆炸追加斜线斩痕、扩散冲击波圈（`Shockwave`）、镜头微缩放脉冲（`camZoom`）、弹跳放大 `!` 暴击飘字与分层 WebAudio 低频重击瞬态音效。

### 5. 无废铁纯金币与废土剧情线（`v57.3` ～ `v57.4`）
- 彻底移除 `scrap` 双货币，建造/修墙/买枪拆解全走金币；鲜肉专注深夜食堂。
- 序幕/开张/4 位并肩战友入伙（老兵张/护士小林/工程师阿强/通信兵小赵）/撤离结局过场与剧情档案馆完整保留，战斗顶部保持清爽无无线电对白条遮挡。

### 6. 自动化验证与发版状态
- `npm test`：28 项单测（规则模拟、食堂 QTE/VIP、战友加成、3 职业 15 天全通机器人与 UI 规范测试）全部通过。
- `npm run e2e`：手机横屏（844×390）下 CDP 真实触摸全走查（含面板横/纵零溢出检查与全场景截图人工核验）全部通过。
- **最新已发布版本**：`v57.5`（GitHub Release 含签名 APK 与单文件电脑版 HTML）。
