# 现在做到哪，下一步做什么

> 先读 `CLAUDE.md`（交接摘要）、`architecture.md`（分层与画面规矩）和 `redesign_proposal.md`（玩法总体方向）。

## 已经做完的（截至 `v57.1`）

### 1. 基础架构（M0 ～ M4 核心闭环已合入）
- 旧版代码完整保留在 `legacy/`；新版采用 `TypeScript + Phaser 3.90 + Preact + vite-plugin-singlefile`，构建产物仍是单个离线 HTML（`dist/index.html`），可直接打进 Android WebView APK。
- 规则层（`src/sim/`）与画面层（`src/view/`）、界面层（`src/ui/`）彻底解耦：规则层纯计算，每秒 60 步，支持带种子复现与机器人（`src/sim/bot.ts`）自动跑完 15 天测试。

### 2. 白天屋顶塔防与 2D 实体物理（M1 ～ M2）
- **2D 小屋实体碰撞与阶梯跳台**：
  - 小屋一楼右侧设有实体砖墙阻挡（`HOUSE_WALL_X = 246`），在地面往左走会被实打实挡在门外，不会穿进屋体贴图。
  - 去掉了旧的「下到院子 / 爬上房顶」瞬移按钮；门廊外侧搭有中层木挑台（`PORCH_Y = -48`）与二层屋顶防守木平台（`ROOF_Y = -92`），玩家可从地面按跳跃键分两跳亲自跳上二楼房顶，站在房顶自带 `+15%` 居高射程加成。
- **右下角主开火键 + 自动瞄准 + 扇形技能键**：
  - 右下角配备 `76×76` 主开火键 `#key-fire`（支持按住连发自动锁定射程内最近目标，也可点击屏幕里的特定僵尸优先集火），外圈弧形排布「跳 / 闪 / 雷 / 技」4 键，互不遮挡。
- **8 把特色武器与升星系统**：
  - 每把武器都有专属机制标签与手感：
    1. **自卫手枪**（`暴击回弹`：+20% 暴击率，击杀立即回膛 2 发子弹）
    2. **左轮手枪**（`重锤穿甲`：大口径弹头穿透 2 名敌人并附带强力击退）
    3. **冲锋枪**（`极速弹幕`：6 发/秒高频弹雨，换弹极快）
    4. **霰弹枪**（`贴脸轰飞`：5 弹片扇形喷射，近距离伤害提升 40% 并强力击退）
    5. **急冻步枪**（`极寒碎冰`：命中挂寒霜减速，打中已减速目标触发范围冰爆溅射）
    6. **反器材狙**（`磁轨全穿`：发射贯穿全屏的金红磁轨光束，直线穿透最多 4 名目标）
    7. **电浆炮**（`连环雷暴`：命中后在周围僵尸间弹射 3 次高压电弧）
    8. **火箭筒**（`焦土高爆`：大范围高爆弹头，引燃地面持续灼烧尸群）
  - 随身最多带 3 把武器；捡到同名武器或花金币升星（最高 ★5），满星再捡自动折算废铁。
- **统一哥特像素亡灵与 15 天三阶段 Boss**：
  - 全面采用 ansimuz Gothicvania 原生像素亡灵与魔物素材（沼泽行尸、感染镇民、持盾骷髅、冥界猎犬、黑街夜猫、远程喷火食尸鬼、暗影怨灵）。
  - 第 5 天登场 **炼狱巨兽**（`boss_beast`）、第 10 天登场 **深渊魔王**（`boss_demon`）、第 15 天登场 **冥界死神领主**（终局 Boss），带专属顶部血条与远程火球/突进压制。
- **4 炮塔槽位与 3 级路障/堡垒升级**：
  - 2 个二楼屋顶塔位 + 2 个庭院阵地塔位；支持机枪塔、冰霜减速塔、电弧连锁塔、重炮高爆塔 4 种分支及 3 级强化。
  - 路障与酒馆堡垒均支持 3 级外观与机制演进（尖刺反伤、电网反伤、屋顶重机枪协防、夜间自动修墙）。

### 3. 夜晚横截面酒馆与深夜小食堂模拟经营（M3 ～ M4）
- **哥特酒馆横截面（`tavern_interior.png`）**：
  - 清场选完天赋后自动进入温暖的横截面木石酒馆屋内，左侧是燃着火苗动画（`fx_stove`）的铁锅灶台，中间是橡木餐桌，右侧是军火商铺吧台与防线工坊。
- **深夜小食堂熟客堂食点单**：
  - 每晚自动迎来 3 位幸存者熟客（阿狗、七姐、老包、泥鳅）坐在餐桌旁，头顶冒出想吃的招牌菜气泡。
  - 在 `#panel-kitchen` 中消耗鲜肉为熟客端上对应菜肴（椒麻烤肉串、废土菌菇炖肉汤、战前火焰牛排），可赚取丰厚金币打赏与暖心台词；3 位熟客全部招待完毕额外触发「满堂喝彩」小费与生命恢复。
  - 同时支持预留明日出战特餐（次日整天提供伤害/攻速/暴击或生命上限加成）与剩余鲜肉一键爆炒变现。
- **极简顶栏、音效音乐与存档**：
  - 左上角顶栏精简为单行 3 胶囊（`生命/护甲`、`路障/酒馆耐久`、`已选天赋`）。
  - 内置 WebAudio 合成器背景音乐（白天战斗 / 夜晚酒馆双曲目）与全套动作音效，支持一键静音与 `localStorage` 自动存档。
