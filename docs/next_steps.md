# 现在做到哪，下一步做什么

> 先读 `CLAUDE.md`（交接摘要）、`architecture.md`（分层与画面规矩）和 `redesign_proposal.md`（玩法总体方向）。

## 已经做完的（截至 `v59.0`）

### 1. 基础架构（M0 ～ M4 核心闭环完整落地）
- 旧版代码完整保留在 `legacy/`；新版采用 `TypeScript + Phaser 3.90 + Preact + vite-plugin-singlefile`，构建产物仍是单个离线 HTML（`dist/index.html`），可直接打进 Android WebView APK。
- 规则层（`src/sim/`）与画面层（`src/view/`）、界面层（`src/ui/`）彻底解耦：规则层纯计算，每秒 60 步，支持带种子复现与机器人（`src/sim/bot.ts`）自动跑完 15 天测试。

### 2. 8 把暮夜兵器特色分化 + 开源真实像素与音画统一（`v58.0`～`v59.0`）
- 每把兵器拥有清晰的价格-输出阶梯、特征标签、契合属性的开源像素外观与视听表现：
  - `猎手双铳`：扳机二连点射 + 20% 高暴击 + 击杀立刻回膛 +2 发。
  - `重锤左轮`：重型穿甲 2 人 + 命中自动跳弹追击近邻 + 击退震慑。
  - `连珠火铳`：持续开火管口升温加速，高热下每 3 发化作灼烧穿甲火弹并配蓄热条。
  - `双管龙息铳`：6 发贯穿扇形龙息弹，中近距 1.5× 爆燃强击退并点燃尸群。
  - `寒霜连铳`：高减速深冻弹，命中已减速目标引爆碎冰溅射与冻结定身。
  - `猩红圣铳`：瞬发 hitscan 全屏贯穿圣光束，对焦骨巨尸与首领 +35%（满星 +50%）破甲伤害。
  - `秘蓝法杖`：多段麻痹连锁雷弧，命中燃烧或冰冻敌人触发 +35% 元素超载爆炸。
  - `焦土爆炎炮`：轻度自导追踪高爆弹，轰炸大圈并铺设 3.5 秒持续燃烧火海。
- **全面接入开源真实音频与循环 BGM**：零自主合成波形，40 个采样音效与 3 首无缝循环 BGM（酒馆 / 守夜摇滚 / 首领金属）全部源自开源仓库真人作品（CC0 / CC-BY 署名详见 `assets/CREDITS.md`），统一提升响度并支持 Android 离线直接解码。

### 3. 泰拉瑞亚立体攻防、战友参战与深夜食堂现场营业（`v59.0`）
- **屋顶 / 门廊 / 庭院三层立体防线与空中威胁**：支持单向挑台立定与摇杆下滑穿层下跳，360° 兼顾迎战第 3 天夜翼魔蝠与第 6 天提灯怨灵；战斗右下完成 **跳跃在上、闪避在下** 键位互换。
- **四位战友协同参战与要塞沙盘**：老兵张、药师小林、铁匠阿强、哨兵小赵全面换装开源像素角色动作图并在屋顶、门廊与前院亲自迎敌/控场/修墙；「防线工坊 · 要塞沙盘」采用空间拓扑布局并支持炮塔索敌重心切换（最近 / 首领 / 对空）。
- **深夜食堂实景营业与极简交互**：左墙灶台直接呼出实时火候 QTE，炒好端盘亲手送至食客餐桌；营地底栏精简为「食堂」「迎战」，右下角配备情景智能互动键靠近食客、战友、炉灶、铁匠与木门一键直达。
